Extract causal, temporal, or logical relationships between events from the following text.

**Output Format**: Return a JSON object with this exact structure:

```json
{
  "triples": [
    {
      "subject": "first event",
      "predicate": "relationship type",
      "object": "second event",
      "confidence": 0.0-1.0
    }
  ]
}
```

**Examples**:

Input: "The meeting was postponed due to the storm. After the delay, they rescheduled for next week."
Output:
```json
{
  "triples": [
    {"subject": "storm", "predicate": "caused", "object": "meeting postponement", "confidence": 0.9},
    {"subject": "meeting postponement", "predicate": "preceded", "object": "rescheduling", "confidence": 0.95},
    {"subject": "delay", "predicate": "led_to", "object": "rescheduling for next week", "confidence": 0.85}
  ]
}
```

Input: "The product launch succeeded, which enabled the company's expansion into new markets."
Output:
```json
{
  "triples": [
    {"subject": "product launch", "predicate": "succeeded", "object": "expansion into new markets", "confidence": 0.9},
    {"subject": "product launch success", "predicate": "enabled", "object": "company expansion", "confidence": 0.85}
  ]
}
```

**Pay special attention to**:
- **Temporal sequence**: Use predicates like "before", "after", "during", "preceded", "followed" for timing
- **Causal connections**: Use "caused", "led_to", "resulted_in", "enabled", "prevented" for cause-effect
- **Duration**: Capture "lasted", "ongoing", "completed" when duration is mentioned
- **Conditional relationships**: Use "required", "depended_on", "contingent_on" for dependencies

**Important Guidelines**:
- Confidence should reflect certainty: 0.9+ for explicit causal/temporal links, 0.6-0.8 for inferred relationships
- Capture both direct and indirect event relationships
- Preserve the temporal or logical ordering in the subject-predicate-object structure
