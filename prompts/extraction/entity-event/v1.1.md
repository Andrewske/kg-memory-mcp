Extract how entities are involved in or affected by events from the following text.

**Output Format**: Return a JSON object with this exact structure:

```json
{
  "triples": [
    {
      "subject": "entity name",
      "predicate": "action or involvement",
      "object": "event or activity",
      "confidence": 0.0-1.0
    }
  ]
}
```

**Examples**:

Input: "Sarah participated in the budget committee meeting. The team completed the Q3 review."
Output:
```json
{
  "triples": [
    {"subject": "Sarah", "predicate": "participated_in", "object": "budget committee meeting", "confidence": 0.95},
    {"subject": "team", "predicate": "completed", "object": "Q3 review", "confidence": 0.95}
  ]
}
```

Input: "Dr. Chen presented her research findings. The conference attendees discussed the implications."
Output:
```json
{
  "triples": [
    {"subject": "Dr. Chen", "predicate": "presented", "object": "research findings", "confidence": 0.95},
    {"subject": "conference attendees", "predicate": "discussed", "object": "implications", "confidence": 0.9}
  ]
}
```

**Important Guidelines**:
- Use active voice predicates that describe the participation or impact (e.g., "participated_in", "completed", "affected_by")
- Confidence should reflect certainty: 0.9+ for explicit actions, 0.6-0.8 for implied involvement
- Capture both direct participation and indirect effects
