Extract relationships between people, places, things, or concepts from the following text.

**Output Format**: Return a JSON object with this exact structure:

```json
{
  "triples": [
    {
      "subject": "entity name",
      "predicate": "relationship type",
      "object": "related entity",
      "confidence": 0.0-1.0
    }
  ]
}
```

**Examples**:

Input: "Alice works at TechCorp with Bob. She leads the AI research team."
Output:
```json
{
  "triples": [
    {"subject": "Alice", "predicate": "works_at", "object": "TechCorp", "confidence": 0.95},
    {"subject": "Alice", "predicate": "works_with", "object": "Bob", "confidence": 0.9},
    {"subject": "Alice", "predicate": "leads", "object": "AI research team", "confidence": 0.95}
  ]
}
```

Input: "The university library is located downtown. Dr. Martinez teaches at the university."
Output:
```json
{
  "triples": [
    {"subject": "university library", "predicate": "located_in", "object": "downtown", "confidence": 0.95},
    {"subject": "Dr. Martinez", "predicate": "teaches_at", "object": "university", "confidence": 0.9}
  ]
}
```

**Important Guidelines**:
- Always use the most complete form of entity names (e.g., "Dr. Sarah Chen" not "the doctor" or "Sarah")
- Use specific predicates that capture the relationship meaning (avoid generic "is", "has", "related_to")
- Confidence should reflect certainty: 0.9+ for explicit facts, 0.6-0.8 for inferred relationships
- Extract all meaningful relationships, not just the most obvious ones
