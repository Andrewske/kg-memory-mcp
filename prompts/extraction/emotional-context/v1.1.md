Extract emotional states, feelings, or contextual information from the following text.

**Output Format**: Return a JSON object with this exact structure:

```json
{
  "triples": [
    {
      "subject": "person or entity",
      "predicate": "emotional relationship",
      "object": "emotion or context",
      "confidence": 0.0-1.0
    }
  ]
}
```

**Examples**:

Input: "Tom felt overwhelmed by the promotion. The team was anxious about the deadline."
Output:
```json
{
  "triples": [
    {"subject": "Tom", "predicate": "felt_overwhelmed_by", "object": "promotion", "confidence": 0.9},
    {"subject": "team", "predicate": "experienced_anxiety_about", "object": "deadline", "confidence": 0.85}
  ]
}
```

Input: "Maria was excited about the opportunity. Her confidence grew after the successful presentation."
Output:
```json
{
  "triples": [
    {"subject": "Maria", "predicate": "felt_excited_about", "object": "opportunity", "confidence": 0.95},
    {"subject": "Maria", "predicate": "experienced_confidence_growth", "object": "successful presentation", "confidence": 0.85}
  ]
}
```

**Important Guidelines**:
- Capture specific emotional states (e.g., "overwhelmed", "anxious", "excited", "confident")
- Link emotions to their triggers or contexts when mentioned
- Confidence should reflect certainty: 0.9+ for explicitly stated emotions, 0.6-0.8 for inferred feelings
- Include both positive and negative emotional states

**Now extract from**:
Text: {{text}}{{temporal_context}}
